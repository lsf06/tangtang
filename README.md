## 📋 项目简介

### 项目背景

随着国内人口老龄化程度不断加剧，国民饮食结构不规律、作息紊乱等问题普遍存在，糖尿病已成为高发慢性疾病，居家血糖健康管理需求持续攀升。传统血糖监测多为有创检测模式，存在诸多明显短板：

- ❌ 依赖一次性试纸耗材，检测成本高
- ❌ 采血过程存在疼痛感，老年用户抵触性强
- ❌ 操作步骤繁琐，依从性差
- ❌ 数据零散、不易追溯、监测不连贯
- ❌ 无法结合长期数据进行综合分析
- ❌ 缺少实时预警、语音提醒和远程家属联动

尤其对于独居老年患者、视力不佳、行动不便及怕痛人群，传统有创设备使用门槛高、体验差，难以实现高频次、常态化自主健康管理。

### 项目目标

本项目摒弃传统指尖采血方案，采用**近红外光谱光学无创检测技术**，依托物联网、长周期数据统计、AI 智能分析、语音播报及网络通信技术，搭建一套轻量化、智能化的物联网无创血糖分析仪与远程监护系统。

**核心能力**：
- ✅ **无采血、无耗材、无痛无创**自主检测
- ✅ AI 智能分析（单次 + 周期趋势研判）
- ✅ 全程语音播报交互
- ✅ 异常预警提醒
- ✅ 家属远程联动监护
- ✅ 网络远程通话

## ✨ 功能特性

### 🌈 光学无创血糖趋势采集

- **无创检测**：近红外光谱技术，无需采血、无需试纸、无疼痛感
- **高频复测**：可随时随地进行多次检测，支持常态化监测
- **双模式工作**：手动单次检测 + 定时提醒检测
- **全场景覆盖**：空腹、餐后、运动前后等多种场景
- **趋势监测**：短时间多次复测，精准捕捉血糖动态变化

### 🔊 全场景语音播报交互

- **自动播报**：检测完成后自动播报血糖数值
- **AI 解读播报**：异常状态解读、健康调理建议语音输出
- **周期总结播报**：周/月周期性血糖总结与管控注意事项
- **无障碍设计**：无需操作屏幕，听觉即可获取完整信息
- **适老化优化**：适配视力不佳、操作生疏的老年用户

### 🤖 AI 单次 + 周期智能分析

- **单次分析**：即时判断血糖状态（偏高/偏低/正常/异常波动）
- **周期分析**：周/月维度多维度数据分析，总结长期波动规律
- **智能区分**：区分偶然突发异常与习惯性血糖问题
- **个性化建议**：饮食、运动、作息、用药全方位指导
- **长周期数据统计**：依托无创高频复测优势，积累高密度历史数据

### 🚨 血糖异常预警与远程监护

- **阈值监测**：内置标准血糖阈值体系，实时监测数据
- **精准捕捉**：识别低血糖、高血糖、血糖异常波动等高危情况
- **声光提醒**：本地触发声光报警，警示用户及时关注
- **家属推送**：异常预警信息实时推送至家属监护端
- **三级防护**：居家自测监护 + 家属远程联动 + 社区医护兜底

### 📞 双向远程通话联动

- **加密通话**：低延迟、加密式网络远程通话
- **双通路通信**：WiFi 与移动网络双通路保障
- **一键呼叫**：患者身体不适时一键紧急呼叫家属
- **主动通话**：家属可主动发起远程通话沟通
- **自动触发**：高危异常场景自动触发呼叫家属
- **通话记录**：云端自动留存，便于后续追溯

### 📊 历史数据存储与趋势溯源

- **永久存储**：云端永久存储全部检测数据
- **趋势曲线**：自动生成精细化血糖波动趋势曲线
- **周期报表**：每日/每周/每月数据统计与报表
- **规律分析**：清晰掌握长期血糖变化规律与管控效果
- **诊疗参考**：为日常健康调整、医生诊疗提供数据支撑

### 🔐 设备与隐私安全管理

- **设备管理**：设备绑定、解绑、在线状态监测
- **状态监控**：实时监控设备电量、网络状态、传感器工作状态
- **传输加密**：TLS/SSL 加密协议保护数据传输
- **存储加密**：AES 加密算法完成本地数据脱敏保存
- **权限隔离**：Token 动态鉴权 + 患者/家属独立权限隔离

## 🛠️ 硬件选型

### 前端光学无创采集终端

本系统硬件层采集终端采用**近红外光谱无创血糖检测模块 + ESP32-S3-EYE 开发板**的自研嵌入式架构。

| 组件 | 说明 |
|------|------|
| **主控板** | ESP32-S3-EYE 开发板 |
| **采集模块** | 近红外光谱无创血糖检测模块 |
| **通信方式** | UART 串口直连 + WiFi/蓝牙双模上传 |

**近红外光谱无创模块特性**：
- 集成特定波段近红外光源发射单元
- 高灵敏度光电接收传感器
- 光谱信号放大电路、高速 ADC 转换电路
- 环境光抑制与温度补偿单元
- 串口输出光谱数据与血糖解析值

**核心优势**：
- ✅ **无创无耗材**：无需指尖采血、无需一次性试纸、无疼痛感
- ✅ **硬件适配度高**：ESP32-S3-EYE 自带多路 UART/IC 串口，直接对接
- ✅ **开发自由度高**：自主编写光谱降噪、环境干扰过滤、温度补偿算法
- ✅ **检测逻辑先进**：基于葡萄糖近红外光谱特异性吸收原理建模
- ✅ **低成本易采购**：模块价格低廉、体积小巧、低功耗
- ✅ **拓展性强**：自带 WiFi、蓝牙、USB 通信能力

**工作流程**：
```
近红外光源发射 → 皮肤组织反射/透射 → 传感器接收光谱信号 
→ 光电转换与放大 → 串口传输至 ESP32-S3-EYE 
→ 数据校验/降噪/温度补偿 → WiFi 加密上传至边缘平台
```

### 边缘算力平台（三种方案）

#### 方案一：树莓派 5（入门实训优选）
- 四核处理器，标配 WiFi/蓝牙
- 部署难度低，开发资料丰富
- 可稳定运行轻量化 AI 模型、语音播报算法
- 适合项目开发与功能演示

#### 方案二：NVIDIA Jetson Orin Nano（高性能落地优选）
- 16 TOPS AI 推理算力，原生支持 CUDA 加速
- 高效运行光学血糖分析模型、光谱特征拟合算法
- 低延迟、高稳定性，适合 7×24 小时运行
- 支持硬件级多媒体编解码加速

#### 方案三：瑞芯微 RK3588（国产高性能优选）
- 6 TOPS 自研 NPU 算力，支持 INT4/INT8/FP18 混合运算
- 国产芯片自主可控
- 性价比高、功耗均衡、拓展性强
- 兼容 TensorFlow、PyTorch 等主流框架

## 🚀 快速开始

### 环境要求

- ESP32-S3-EYE 开发板
- 近红外光谱无创血糖检测模块
- 边缘计算平台（树莓派 5 / Jetson Orin Nano / RK3588）
- WiFi 网络连接

### 安装步骤

#### 1. 硬件连接

```
┌────────────────────────────┐         ┌──────────────────┐
│  近红外光谱无创血糖检测模块   │         │   ESP32-S3-EYE   │
├────────────────────────────┤         ├──────────────────┤
│  TX  ───────────────────→  │  RX     │                  │
│  RX  ←──────────────────  │  TX     │                  │
│  GND  ──────────────────→  │  GND    │                  │
│  VCC  ──────────────────→  │  5V     │                  │
└────────────────────────────┘         └──────────────────┘
                                                │
                                                ↓ WiFi/蓝牙
                                        ┌──────────────────┐
                                        │   边缘计算平台    │
                                        │  (树莓派 5 等)      │
                                        └──────────────────┘
```

#### 2. 软件部署

**ESP32-S3-EYE 固件**
```bash
# 克隆固件仓库
git clone https://github.com/your-repo/glucometer-firmware.git

# 进入目录
cd glucometer-firmware/esp32-s3

# 配置 ESP-IDF 环境
export IDF_PATH=$HOME/esp/esp-idf

# 编译并烧录
idf.py build flash monitor
```

**边缘服务部署**
```bash
# 克隆服务代码
git clone https://github.com/your-repo/glucometer-service.git

# 进入目录
cd glucometer-service

# 安装依赖
pip install -r requirements.txt

# 启动服务
python main.py
```

## 📈 项目规划

### 短期基础优化阶段（6 周）

聚焦现有无创检测功能的轻量化打磨与光学采集性能优化：

- 优化前端光谱数据预处理程序（基于 ESP32-S3-EYE）
- 完善光谱滤波算法、环境光抑制机制
- 皮肤差异适配、温度补偿、动作抖动纠错规则
- 解决环境光照变化、人体皮肤差异、轻微晃动导致的信号漂移问题
- 提升无创血糖采集的精准度、数据重复性与运行稳定性

### 中期功能拓展与性能升级阶段

**性能优化**：
- 迭代优化边缘端轻量化 AI 分析模型
- 扩充多体质、多年龄段、多肤色、多生活场景样本数据集
- 优化光谱特征拟合与模型推理参数
- 优化边缘硬件算力调度机制，降低运行延迟

**功能打磨**：
- 优化语音播报语速、音色与播报逻辑
