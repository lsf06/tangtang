## 📋 项目简介

### 项目背景

随着国内人口老龄化程度不断加剧，糖尿病已成为高发慢性疾病，居家血糖健康管理需求持续攀升。传统血糖监测方式存在诸多短板：

- ❌ 手动采血、人工记录数据
- ❌ 数据零散、不易追溯
- ❌ 无语音提示、无智能指导
- ❌ 无法结合长期数据进行综合分析
- ❌ 缺少实时预警和远程家属联动

### 项目目标

本项目依托**物联网、大数据、AI 智能分析、语音播报及网络通信技术**，搭建一套轻量化、智能化的物联网血糖分析仪与远程监护系统，实现：

- ✅ 自主检测
- ✅ AI 智能分析
- ✅ 语音交互
- ✅ 周期数据分析
- ✅ 远程家属联动监护

## ✨ 功能特性

### 🩸 高精度实时血糖检测
- 数秒内完成血糖数值输出
- 支持空腹、餐后、随机血糖全场景检测
- 手动单次检测与定时提醒检测模式
- 数据实时同步至本地端与云端

### 🔊 全场景语音播报交互
- 自动播报实时血糖数值
- AI 分析结果语音播报（异常解读、健康建议）
- 周/月周期性血糖总结语音播报
- 适配视力不佳、操作生疏的老年用户

### 🤖 AI 单次 + 周期智能分析
- **单次分析**：快速判断血糖状态，生成个性化调理建议
- **周期分析**：调取周/月历史数据，总结长期波动规律
- **智能区分**：区分偶然突发异常与习惯性血糖问题
- **个性化建议**：饮食、运动、作息、用药全方位指导

### 🚨 血糖异常预警与远程监护
- 内置标准血糖阈值体系
- 低血糖、高血糖、血糖骤变实时监测
- 本地声光提醒 + 家属端预警推送
- 第一时间掌握患者风险情况

### 📞 双向远程通话联动
- 低延迟、加密式网络远程通话
- WiFi 与移动网络双通路通信
- 患者一键紧急呼叫家属
- 家属主动发起远程通话
- 高危异常自动触发呼叫

### 📊 历史数据存储与趋势溯源
- 云端永久存储全部检测数据
- 自动生成血糖波动趋势曲线
- 每日/每周/每月数据统计
- 数据可查、可溯、可分析

### 🔐 设备与隐私安全管理
- 设备绑定、解绑、在线状态监测
- 数据加密传输与加密存储
- 权限隔离机制

## 🏗️ 系统架构

### 三层边缘架构设计

本项目采用轻量化、高解耦的**三层物联网架构**，摒弃传统冗余四层架构：

```
┌─────────────────────────────────────────────────────────────┐
│                        展示层                                │
│  ┌─────────────────────┐      ┌─────────────────────┐       │
│  │   本地用户端        │      │   家属监护端        │       │
│  │  (患者端)          │      │   (远程端)          │       │
│  │  - 数据可视化       │      │  - 远程数据查看     │       │
│  │  - 语音播报         │      │  - 异常预警接收     │       │
│  │  - 一键呼叫         │      │  - 主动通话         │       │
│  └─────────────────────┘      └─────────────────────┘       │
└─────────────────────────────────────────────────────────────┘
                              ↕
┌─────────────────────────────────────────────────────────────┐
│                        服务层                                │
│  ┌─────────────────────────────────────────────────────┐    │
│  │              边缘算力平台 (树莓派 5/Jetson/RK3588)    │    │
│  │  - 数据解密校验        - 本地缓存与云端同步          │    │
│  │  - AI 智能分析引擎      - 异常预警判定               │    │
│  │  - 加密通话服务        - 日志本地留存               │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
                              ↕
┌─────────────────────────────────────────────────────────────┐
│                        硬件层                                │
│  ┌─────────────────────────────────────────────────────┐    │
│  │        ESP32-S3-EYE + UART 串口血糖仪模块            │    │
│  │  - 生物传感采集      - 数据预处理                    │    │
│  │  - 语音播报执行      - WiFi/蓝牙双模通信             │    │
│  │  - 本地缓存单元      - 离线独立运行                 │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
```

### 数据流逻辑

```
硬件采集 → 预处理传输 → 边缘 AI 分析 → 智能指令输出 
    → 双端交互联动 → 语音播报执行 → 云端数据归档
```

## 🛠️ 硬件选型

### 前端采集终端

| 组件 | 说明 |
|------|------|
| **主控板** | ESP32-S3-EYE 开发板 |
| **血糖模块** | UART 串口血糖检测模块 |
| **通信方式** | UART 串口直连 + WiFi/蓝牙双模上传 |

**核心优势**：
- 硬件适配度高：ESP32-S3-EYE 自带多路 UART 串口，直接对接血糖仪模块
- 开发自由度高：自主编写解析协议、数据校验、异常过滤算法
- 检测精度稳定：符合家用血糖检测技术标准
- 低成本易采购：模块价格低廉、体积小巧、低功耗

### 边缘算力平台（三种方案）

#### 方案一：树莓派 5（入门实训优选）
- 四核处理器，标配 WiFi/蓝牙
- 部署难度低，开发资料丰富
- 适合项目开发与功能演示

#### 方案二：NVIDIA Jetson Orin Nano（高性能落地优选）
- 16 TOPS AI 推理算力
- 原生支持 CUDA 加速
- 低延迟、高稳定性，适合 7×24 小时运行

#### 方案三：瑞芯微 RK3588（国产高性能优选）
- 6 TOPS 自研 NPU 算力
- 国产化自主可控
- 性价比高、功耗均衡

## 🚀 快速开始

### 环境要求

- ESP32-S3-EYE 开发板
- UART 串口血糖检测模块
- 边缘计算平台（树莓派 5 / Jetson Orin Nano / RK3588）
- WiFi 网络连接

### 安装步骤

#### 1. 硬件连接

```
┌──────────────────┐         ┌──────────────────┐
│  UART 血糖仪模块   │         │   ESP32-S3-EYE   │
├──────────────────┤         ├──────────────────┤
│  TX  ──────────→  │  RX     │                  │
│  RX  ←──────────  │  TX     │                  │
│  GND ──────────→  │  GND    │                  │
│  VCC ──────────→  │  5V     │                  │
└──────────────────┘         └──────────────────┘
                                      │
                                      ↓ WiFi/蓝牙
                              ┌──────────────────┐
                              │   边缘计算平台    │
                              │  (树莓派 5 等)     │
                              └──────────────────┘
```

#### 2. 软件部署

**ESP32-S3-EYE 固件**
```bash
# 克隆固件仓库
git clone https://github.com/your-rei/glucometer-firmware.git

# 进入目录
cd glucometer-firmware/esp32-s3

# 配置 ESP-IDF 环境
export IDF_PATH=$HOME/esp/esp-idf

# 编译并烧录
idf.py build flash monitor
```

**边缘服务部署**
```bash
# 克隆服务代码
git clone https://github.com/your-repo/glucometer-service.git

# 进入目录
cd glucometer-service

# 安装依赖
pip install -r requirements.txt

# 启动服务
python main.py
```

### 配置说明

创建配置文件 `config.yaml`：
```yaml
device:
  serial_port: "/dev/ttyUSB0"
  baud_rate: 115200
  
network:
  wifi_ssid: "your_wifi_ssid"
  wifi_password: "your_wifi_password"
  
ai:
  model_path: "./models/gluco_analyzer.onnx"
  
threshold:
  low_glucose: 3.9    # mmol/L
  high_glucose: 10.0  # mmol/L
  
family:
  - name: "家属 1"
    phone: "138****1234"
  - name: "家属 2"
    phone: "139****5678"
```
