## 模型用途

本模型用于居家健康监护场景下的多模态生理数据分析，主要功能包括：

- **健康基线学习**: 学习用户个人化的健康指标基线
- **异常检测**: 识别偏离正常范围的健康异常
- **趋势分析**: 分析健康指标的长期变化趋势
- **健康评分**: 综合计算用户健康状态评分

## 输入数据

### 传感器输入

| 传感器 | 数据类型 | 范围 | 单位 |
|--------|----------|------|------|
| MAX30102 | 心率 | 40-200 | BPM |
| MAX30102 | 血氧饱和度 | 70-100 | % |
| MLX90614 | 体温 | 30-45 | °C |
| 近红外光谱 | 光学特征 | 0-1023 | ADC 值 |

### 数据格式

```json
{
  "timestamp": "2026-06-07T20:00:00Z",
  "device_id": "esp32_s3_eye_001",
  "sensors": {
    "heart_rate": 72,
    "spo2": 98,
    "temperature": 36.5,
    "near_ir_data": 512
  },
  "metadata": {
    "battery_level": 85,
    "signal_quality": 0.95
  }
}
```

## 训练数据

### 数据来源

| 数据类型 | 来源 | 样本数 |
|----------|------|--------|
| 公开数据集 | MIMIC-III, PhysioNet | 待补充 |
| 模拟数据 | 传感器模拟器 | 10,000+ |
| 实测数据 | 项目测试 | 待收集 |

### 数据预处理

1. **数据清洗**: 去除异常值和噪声
2. **归一化**: 将不同量纲的数据标准化
3. **时间对齐**: 多传感器数据时间戳对齐
4. **缺失值处理**: 插值或标记

## 公平性与偏差

### 已知偏差

| 偏差类型 | 描述 | 缓解措施 |
|----------|------|----------|
| **年龄偏差** | 模型主要针对老年人群体优化 | 收集各年龄段数据 |
| **肤色偏差** | 光学传感可能受肤色影响 | 多光源校准 |
| **健康状态偏差** | 训练数据主要来自健康人群 | 增加病患数据 |

## 伦理考虑

### 隐私保护

- 所有数据本地处理，不上传云端（可选）
- 用户数据加密存储
- 用户可完全控制数据

### 知情同意

- 明确告知用户数据用途
- 提供数据删除选项
- 不收集个人身份信息
