✨ 核心功能

🩸

无创血糖检测

近红外光谱技术，无痛检测血糖水平，让手指从千疮百孔中解脱

📊

多模态传感融合

心率、血氧、体温、光学特征多维度数据采集与分析

🗣️

语音交互播报

智能语音播报健康状态，比老妈唠叨但比老妈准确

📱

远程家属监护

家属端实时查看数据，异常预警推送，双向视频通话

📈

AI 健康分析

健康基线学习、异常检测、趋势分析、智能评分

🔔

智能告警系统

分级告警、本地声光报警、远程推送通知
