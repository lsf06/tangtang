## 录制建议

### 工具推荐

| 用途 | 工具 | 备注 |
|------|------|------|
| 屏幕录制 | OBS Studio | 免费开源 |
| 视频剪辑 | DaVinci Resolve | 免费版功能强大 |
| 配音 | 剪映/CapCut | AI 配音 |
| 概念图 | Midjourney | AI 生成 |

### 录制步骤

1. **准备环境**
   - 确保设备正常运行
   - 清理桌面，保持背景简洁
   - 准备测试数据

2. **分步录制**
   - 按场景分段录制
   - 每段预留 5 秒缓冲
   - 录制时保持安静

3. **后期制作**
   - 剪辑拼接各段
   - 添加转场效果
   - 添加字幕
   - 添加背景音乐（音量调低）

4. **导出设置**
   - 分辨率：1920x1080
   - 帧率：30fps
   - 码率：8-12 Mbps
   - 格式：MP4 (H.264)

## AI 生成演示视频方案

如果无法进行实物录制，可以使用 AI 生成概念演示视频：

### 方案 A：使用 Runway ML

1. 上传产品概念图
2. 使用"Image to Video"功能生成动态效果
3. 添加文字叠加层
4. 导出视频

### 方案 B：使用 Pika Labs

1. 编写场景描述 prompt
2. 生成视频片段
3. 拼接多个片段
4. 添加配音

### 方案 C：使用 HeyGen

1. 创建虚拟主播
2. 输入脚本
3. 生成口播视频
4. 叠加屏幕录制内容
